# Rules

## Project rules
- Follow the current Major Project and supervisor requirements.
- Include real development, not pure research.
- Mission AI alignment must be substantive.
- Novelty claims require literature support.
- Never fabricate metrics, figures, experiments, or citations.
- Maintain the supervisor meeting diary.
- Treat current mentor instructions as authoritative when they refine earlier assumptions.

## Technical rules
- PyTorch only for the deep-learning implementation.
- No Keras, TensorFlow, MATLAB.
- Never modify raw dataset files.
- Record experiment configuration.
- Change one major experimental factor at a time unless studying interactions.
- Accuracy is not the sole segmentation metric.
- Never report an experiment as complete until it has actually run.

## AI coding rules
AI-generated code is assistance, not evidence. Run it, test it, inspect it, understand its inputs/outputs, and keep a short viva explanation.

## Agent rules
The agent must make an observable decision using defined inputs and a defined policy/objective. A fixed if/else baseline must not be presented as a learned/intelligent agent without saying so.
