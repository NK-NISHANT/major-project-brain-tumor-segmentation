- **Review Gate:** Gate 1.

### EXP-04: Architectural Expansion Pilots (Phase B)
- **Objective:** Evaluate ResUNet-2D, U-Net with ResNet-34 encoder, TransUNet, and 3D U-Net feasibility on the 158-case development split.
- **Candidates & Rationale:**
  1. *ResUNet-2D:* Residual skip connections to alleviate vanishing gradients and enhance boundary sensitivity.
  2. *U-Net with ResNet-34 Encoder:* Transfer-learning feature extraction paired with transposed convolutions.
  3. *TransUNet:* Vision Transformer bottleneck for global contextual dependencies.
  4. *3D U-Net Feasibility:* Rigorous study of VRAM consumption, patch cropping ($96 \times 96 \times 96$), and sliding-window inference on 8 GB GPU.
- **Protocol:** 5 epochs per candidate on 158 cases, batch size 16 (or 8 for TransUNet), `DiceBCELoss`, AdamW, lr=0.001.
- **Compute Estimates:**
  - ResUNet-2D: ~45 min `[ESTIMATE]`, ~2.4 GB VRAM `[ESTIMATE]`.
  - ResNet-34 U-Net: ~50 min `[ESTIMATE]`, ~2.8 GB VRAM `[ESTIMATE]`.
  - TransUNet: ~1.8 hours `[ESTIMATE]`, ~4.2 GB VRAM `[ESTIMATE]`.
  - 3D Feasibility Study: Memory profiling script (CPU/GPU allocation tracker), ~15 min.
- **Success Criteria:** Candidate architectures pass unit tests, achieve stable loss convergence, and generate valid segmentation probabilities without numerical divergence.
- **Review Gate:** Gate 2.

### EXP-05: Multi-Metric Model Selection & Pareto Analysis (Phase C)
- **Objective:** Benchmark all baseline and candidate models across WT, TC, ET Dice/IoU, boundary miss rate, false alarm rate, latency, and memory on the 39-case validation set.
- **Methodology:** Compute multi-metric trade-offs and Pareto efficiency frontier (accuracy vs. latency vs. boundary recall).
- **Compute:** ~20 minutes on GPU.
- **Success Criteria:** Documented trade-offs; selection of the final frozen portfolio (Primary Model, Secondary Boundary Specialist, Fallback Arbitrator).
- **Review Gate:** Gate 3.

### EXP-07: 3-Way Leakage-Safe Patient Partitioning (Phase D)
- **Objective:** Establish a permanent, leakage-free 3-way partition across all eligible cases in the BraTS archive.
- **Split Ratios:** Training (~70%, ~875 cases `[ESTIMATE]`), Validation (~15%, ~188 cases `[ESTIMATE]`), and Held-Out Pristine Test (~15%, ~188 cases `[ESTIMATE]`) using seed 42.
- **Integrity Rule:** Slices from the same patient must never cross partitions. The historical 39 validation cases remain cataloged and isolated from the pristine test set.
- **Deliverables:** `data/splits/train_manifest.json`, `val_manifest.json`, `test_manifest.json`.
- **Review Gate:** Gate 4.

### EXP-09: Multi-Signal Reliability Agent Calibration (Phase F)
- **Objective:** Expand the agent beyond the 2-model context fallback prototype to integrate whole-brain background ambiguity ($H_{\text{brain}}$), spatial axial continuity ($z \pm k$), candidate disagreement, and slice position index.
- **Methodology:** Calibrate routing thresholds strictly on the validation partition (~188 cases `[ESTIMATE]`) to avoid test set contamination.
- **Baselines:** Standalone models, naive averaging ensemble, random fallback, and offline Oracle ceiling.
- **Success Criteria:** Agent demonstrates statistically significant improvement over standalone models or random fallback ($p < 0.05$), with documented sensitivity/specificity trade-offs.
- **Review Gate:** Gate 7.
